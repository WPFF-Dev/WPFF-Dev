# WPFF

WordPress and WooCommerce plugins, built and maintained by the team behind [wpff.dev](https://wpff.dev/),
and field notes from running them on real stores.

## Plugins

| Plugin | What it does |
|---|---|
| [WPFF Promoter](https://wpff.dev/plugins/promoter/) | An SEO operator that audits, writes and measures — and can undo everything it did. |
| [WPFF WooCommerce Webhooks](https://wpff.dev/plugins/wc-webhooks/) | Decide exactly which order fields leave your store, and read what the other end answered. |
| [WPFF Priority ERP Integration](https://wpff.dev/plugins/priority-erp/) | WooCommerce orders and customers in Priority ERP, pushed over OData with every sync logged. |
| [WPFF AI ChatBot](https://wpff.dev/plugins/ai-chatbot/) | An assistant that answers from your own pages, products and documents — not from the open web. |
| [WPFF Site Analytics](https://wpff.dev/plugins/site-analytics/) | Self-hosted WordPress analytics that keeps counting correctly behind page caching. |
| [WPFF Content Migrate](https://wpff.dev/plugins/content-migrate/) | Move content, ACF data, users, orders and media between WordPress sites. |

The full catalogue is at [wpff.dev/plugins](https://wpff.dev/plugins/).
